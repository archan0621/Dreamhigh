# Dreamhigh

> 개발자를 위한 취업 준비 관리 macOS 앱

Dreamhigh는 개발자의 취업 준비 과정을 체계적으로 관리하고, AI를 활용하여 실질적인 인사이트를 제공하는 macOS 네이티브 애플리케이션입니다.

## ✨ 주요 기능

### 📝 지원 내역 관리
- **채용공고 자동 분석**: URL을 입력하면 자동으로 크롤링하여 핵심 정보를 AI가 구조화
- **면접 전형별 기록**: 코딩테스트, 기술면접, 인성면접 등 전형별 질문/답변/회고 기록
- **서류/면접 상태 추적**: 각 전형별 진행 상황 실시간 업데이트
- **이력서 버전 연동**: 어떤 이력서로 지원했는지 추적 가능

### 📄 이력서 관리
- **PDF 이력서 버전 관리**: 여러 버전의 이력서를 체계적으로 관리
- **AI 피드백**: 시니어 개발자 관점에서 이력서 분석 및 개선점 제안
  - 종합 점수 (0-100점)
  - 강점/개선점 분석
  - 예상 면접 질문
  - 섹션별 상세 피드백

### 🎯 AI 취업 인사이트
- **합격/불합격 패턴 분석**: 과거 지원 내역을 기반으로 한 심층 분석
- **회사 유형별 적합도**: 대기업, 스타트업 등 어떤 회사에 강점이 있는지 분석
- **이력서 레벨 평가**: 주니어/중급/시니어 수준 평가 및 개선 방향
- **기술 스택 최적화**: 불필요한 기술 스택 제거 및 추가할 항목 제안
- **단계별 액션 아이템**: Phase 1~3로 구성된 구체적인 개선 전략

### 📊 AI 토큰 사용량 추적
- **실시간 사용량 모니터링**: 모든 AI 호출의 토큰 사용량 자동 기록
- **비용 계산**: Claude API 기준 예상 비용(USD) 실시간 표시
- **서비스별 통계**: 채용공고 분석, 이력서 피드백, 인사이트 리포트별 사용량 확인

## 🚀 설치 방법

### Homebrew (권장)

```bash
# Tap 추가
brew tap archan0621/dreamhigh

# 설치
brew install --cask dreamhigh
```

### 수동 설치

1. [Releases](https://github.com/archan0621/dreamhigh/releases) 페이지에서 최신 버전 다운로드
2. DMG 파일을 열고 Applications 폴더로 드래그

## 🔧 설정

### AI 설정
1. 앱 좌측 상단 메뉴에서 "Settings..." 선택
2. AI Provider로 "Claude" 선택
3. 원하는 모델 선택 (Sonnet 4.5 권장)
4. Claude API 키 입력 ([Anthropic Console](https://console.anthropic.com/)에서 발급)

> **API 키 보안**: 모든 API 키는 macOS Keychain에 안전하게 저장됩니다.

## 💡 사용 팁

### 채용공고 분석
- 채용공고 URL을 입력하면 자동으로 크롤링 및 AI 분석이 진행됩니다
- 지원 기업, 포지션, 요구사항 등이 자동으로 추출되어 저장됩니다

### 이력서 피드백
- PDF 이력서를 업로드하고 "피드백 받기" 버튼을 클릭하세요
- 시니어 개발자 관점에서 작성된 상세한 피드백을 받을 수 있습니다
- 여러 버전을 관리하며 각 버전별로 피드백을 비교할 수 있습니다

### 인사이트 리포트
- 최소 3개 이상의 지원 내역이 있어야 분석이 가능합니다
- 이력서 피드백을 받은 후 분석하면 더욱 정확한 인사이트를 얻을 수 있습니다
- 생성된 리포트는 자동으로 저장되어 히스토리로 관리됩니다

## 📦 시스템 요구사항

- macOS 14.0 (Sonoma) 이상
- Apple Silicon (M1/M2/M3) 또는 Intel Mac

## 🔐 프라이버시

- 모든 데이터는 로컬 디바이스에 저장됩니다
- API 키는 macOS Keychain에 암호화되어 저장됩니다
- AI 분석 시에만 Claude API로 데이터가 전송됩니다
